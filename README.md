# TadpoleLM

## Description

This is a tiny, proof-of-concept LLM I created based on my personal notes, similar in scale and nature to Karpathy's NanoGPT. 

- the corpus being used is my personal notes (not included here)
   - i wrote it in a very conversational style, lots of "quotes", other fun bad grammar stuff
   - there's also bullets and indents
- the inference prompt is "- i think "
- since it's a super small corpus, i used an LLM to paraphrase and augment it 

Hopefully, we can extend this to something enabling more fun interpretability projects.
